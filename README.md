# KAGE: ZERO SECOND — прототип (шаг 1)

Рабочий прототип боевой системы: движение, **Echo** (запись и повтор
твоих действий) и **ZERO SECOND** (телепорт на позицию Echo + окно
двойного урона), плюс один враг и базовая боёвка.

Сделано на **Three.js** (JavaScript, работает прямо в браузере) —
это самый быстрый способ проверить механики до того, как переносить
игру в полноценный движок (Unreal/Godot/Unity) для финальной 3D-версии.

## Управление

- **WASD** — движение
- **E** — создать Echo (повторяет твои последние ~4 секунды действий)
- **Q** — ZERO SECOND: телепорт на текущую позицию Echo + 0.8с двойного урона
- **Space** — атака (нужно стоять близко к врагу и смотреть на него)

## Как запустить у себя на ноутбуке

Файлы — обычные `index.html`, `style.css`, `game.js`. Открыть просто
двойным щелчком по `index.html` иногда не сработает из-за ограничений
браузера на локальные файлы, поэтому надёжнее запустить локальный
сервер:

**Если стоит Python (обычно уже есть на Windows/Mac):**
1. Открой папку `kage-zero-second` в терминале (в Windows — через
   PowerShell: `cd путь\до\папки`).
2. Выполни: `python -m http.server 8000`
3. Открой в браузере: `http://localhost:8000`

**Или через VS Code:**
1. Установи VS Code, открой папку проекта.
2. Установи расширение **Live Server**.
3. Правой кнопкой по `index.html` → **Open with Live Server**.

## Как выложить на GitHub (пошагово, без командной строки)

1. Зайди на [github.com](https://github.com), войди или зарегистрируйся.
2. Нажми зелёную кнопку **New** (или **+** в правом верхнем углу →
   **New repository**).
3. Введи имя репозитория, например `kage-zero-second`. Выбери
   **Public** (или Private, если не хочешь показывать код другим).
   Не ставь галочку "Add a README" — он уже есть у нас.
4. Нажми **Create repository**.
5. На следующей странице найди ссылку **"uploading an existing
   file"** (или "upload files") — нажми на неё.
6. Перетащи в окно браузера все четыре файла: `index.html`,
   `style.css`, `game.js`, `README.md`.
7. Внизу напиши короткое сообщение коммита, например
   `первый прототип: движение, Echo, ZERO SECOND`.
8. Нажми **Commit changes**.

Готово — код на GitHub.

### Чтобы прототип сразу открывался как веб-страница (GitHub Pages)

1. В репозитории зайди в **Settings** → в левом меню **Pages**.
2. В разделе **Build and deployment → Source** выбери
   **Deploy from a branch**.
3. В **Branch** выбери `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту-две GitHub покажет ссылку вида
   `https://твой-логин.github.io/kage-zero-second/` — открой её,
   и прототип будет играбелен прямо в браузере, без установки чего-либо.
